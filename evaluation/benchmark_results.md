# BusinessIntelligence.ai — Benchmark Results

## LLM vs Non-LLM Method Ownership

| Engine | Method Tag(s) | Produces Numbers? | Role |
|---|---|---|---|
| E1 KPI Store | [SQL] | YES | KPI values, freshness |
| E2 Signal | [STATS] | YES | z-scores, delta%, anomaly flags |
| E3 Diagnostic | [SQL]+[STATS] | YES | contribution percentages |
| Security | [RULES] | NO | entitlement enforcement |
| E4 Evidence | [SQL]+[RETRIEVAL] | NO | retrieval, freshness weights |
| E5 Hypothesis | [LLM] | **NEVER** | hypothesis statements only |
| E6 Challenge | [RULES] | YES | confidence scores (deterministic) |
| E6 Narrative | [LLM_NARRATIVE] | **NEVER** | explains scores only |
| E7 Decision | [LLM] | **NEVER** | action text, persona narrative |
| E8 Outcome | [SIMULATED] | NO | labeled projection |
| E9 Memory | [RETRIEVAL]+[LLM] | **NEVER** | precedent storage/retrieval |

**Core principle:** Numbers come from SQL/STATS/RULES engines only. The LLM never produces quantitative truth.
